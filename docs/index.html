Privacy Policy for SubShelf — Smart YouTube™ Subscription Folders

Effective Date: September 10, 2026
Developer Repository: https://github.com/Shourya3113/SubShelf

SubShelf ("we", "our", or "the extension") provides intelligent subscription categorization and feed curation for YouTube™. We are fundamentally committed to protecting user privacy through a local-first, zero-data-collection architecture.

1. 100% Private & Local-First Architecture

  • Zero Personal Data Collection: We do not collect, transmit, sell, or monetize any personal user data.
  • Local Storage Only: All subscription metadata, custom folder names, category assignments, and user preferences are stored exclusively inside your web browser using Chrome's secure chrome.storage.local API.
  • No External Servers: We do not operate remote tracking servers, analytics endpoints, or external user databases.

2. Information Accessed & Stored

A. YouTube™ Subscriptions Information

The extension accesses channel names, handles, channel IDs (ucId), and channel avatars that are already visible in your native YouTube left sidebar. This is required strictly to enable folder organization and feed filtering on YouTube web pages. This data is never sent outside your computer.

B. Custom Categories & Overrides

Your folder structures, channel-to-folder mappings, and manual exclusions are stored locally on your device.

C. Optional AI API Keys

If you optionally choose to supply your own Google Gemini API key for cloud-based categorization, that key is stored locally in your browser's private storage and is only used to send direct requests from your browser to Google's official Gemini endpoint. We have zero access to your API key.

3. Chrome Permissions Disclosure

Permission Justification & Usage
storage Used to store your subscription folders, channel associations, manual overrides, and preferences locally.
https://*.youtube.com/* Used exclusively to inject the folder accordion interface into YouTube's sidebar and filter subscription feeds.
https://generativelanguage.googleapis.com/* (Optional) Used solely for direct communication with Google Gemini API when the user explicitly triggers AI categorization with their own API key.

4. AI Categorization & Privacy Guarantees

SubShelf provides three tiers of categorization:

  • Chrome Built-in Gemini Nano: Executes 100% on-device on your local hardware. Zero network traffic.
  • Offline Heuristic Engine: Evaluates channel names and handles using deterministic offline keywords and regular expressions. Completely offline.
  • Optional Gemini Cloud API: Transmits only sanitized channel titles and handles directly to Google without user account identifiers.

5. Third-Party Sharing & Tracking

SubShelf does not include third-party trackers, analytics packages, advertising networks, or telemetry scripts. Your viewing habits and subscriptions remain completely private to you.

6. Data Deletion

You can delete all stored data at any time by uninstalling SubShelf from Chrome (chrome://extensions -> "Remove") or using the backup reset option in the extension popup. Removal immediately purges all stored records.

7. Contact

For questions or feedback regarding this Privacy Policy, please submit an issue on our GitHub repository: https://github.com/Shourya3113/SubShelf/issues.
